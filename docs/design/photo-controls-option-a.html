Option A — Photo strip first

This option puts the photo strip itself, not just the button, directly under the place name so the owner's core ask — "photos and the button at the top" — is answered with the content, not only the affordance. A single full-width dusk pill sits above the strip as the one unmistakable entry point, and it stays the only dusk element on the screen so it never competes with the pine primary actions below it. The same photo-strip logic repeats as a split toolbar segment on the plan header and a top banner on the recap page, so "add photos" reads as one consistent colored affordance across the whole product rather than three different patterns.
