## Decisions

1. Joining must never reveal the trip id. `POST /api/recap/:token/join` returns `{joined: true}`. The trip id must only appear in owner surfaces that already hold it.
2. A contributor is a signed-in user with a `trip_members` row for the recap's trip. Contributor actions go through recap-token-scoped endpoints and must be authorized by session plus membership, never by the trip id.
3. Contributors may add photos to any stop in the recap and may delete only photos whose `uploader_user_id` is their own user id.
4. Owner photo upload/delete via the trip link keeps working as today (the owner holds the link).
5. The v20 "Go to the trip and add photos" step 3 becomes "Add your photos" and keeps the user on the recap in contributor mode.
